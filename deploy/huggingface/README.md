# JISER · جسر

Plateforme d'IA pour le contentieux fiscal tunisien : le pont entre le contribuable et l'administration fiscale.

- Code source et documentation : https://github.com/EyaAzzabi/Jiser
- Hackathon national « IA & Finances publiques » 2026 · finaliste

Les données de dossiers sont simulées (calibrées sur les statistiques officielles du ministère des Finances) : aucune donnée réelle de contribuable.
